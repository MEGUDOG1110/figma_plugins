# SVG Link Exporter — Release Notes Draft

複数フレームのリンク付きSVGを、より分かりやすく設定・書き出しできるようになりました。

## 新しくなったこと

- 複数のフレームをまとめて選択し、一度に書き出せるようになりました
- 検出したリンクをフレームごとにグループ表示するようになりました
- SVGの説明をフレームごとに設定できるようになりました
- リンク種別を「URL」と「アンカー」から選択できるようになりました
- リンクごと・フレームごと・選択全体の一括切り替えに対応しました
- 複数のSVGを書き出す場合、ひとつのZIPファイルにまとめて保存するようになりました

## UIの改善

- 選択中のフレーム数とリンク数を確認しやすくしました
- フレーム単位で開閉できる構成にし、設定対象を把握しやすくしました
- 「URL」と「アンカー」の表記を画面全体で統一しました
- レイヤーの命名規則を `link:page_name` に統一し、案内を簡潔にしました

従来の `anchor:` 形式と `link:パス|ラベル` 形式も引き続き利用できます。
